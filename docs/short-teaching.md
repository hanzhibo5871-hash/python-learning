# 简单教学不能省略

“多实践、少文字”不代表打开页面就直接交作业。D01—D28 每个小节先回答三个问题：用来做什么、一般用在哪里、怎么用。每项保持一两句话，基础说明默认可见；长原理和额外细节仍按需展开。

页面顺序为：简短入门说明 → 必要的前置知识卡 → 一个默认展开的完整示例与输出 → 补全/改写练习 → 独立作业与结果对照。示例必须由学习者点击才运行，不能把参考输出伪装成已经执行的结果。没有补全题的程序/文档小节直接进入对应作业；命令与文件片段仍显示操作位置，不当作 Python 执行。

例如函数课先讲“封装重复计算”“用于面积或金额计算”“def 接收参数、return 交回结果、调用后 print 显示”，再展示完整面积例子，最后让学习者编写函数。不能用作业要求代替知识说明，也不能突然要求未教过的异常处理。

## 实现边界

`web/static/teaching-catalog.js` 是按原小节 ID 编写的三项简短说明，不是作业答案或新的练习契约。它与原来的完整课程和练习并存。`test_short_teaching.py` 检查键集合与实际生成课程完全相同；增删小节时必须同步说明。课程生成器及 `data/curriculum.json` 未改变。

`teaching-view.js` 是独立的展示增强层，在原页面完成渲染后为新的 `#section-body` 排列教学顺序。它保留原编辑器、输出节点和事件委托，移动而不复制示例/题目节点；WeakSet 确保结果更新时不会重复插入说明或重新排序。模块不调用 API，不执行代码，不读写学习进度，不改变正式作业与判题条件。新增文件通过原有静态资源机制和 CSP 加载，无外部依赖。

浏览器回归需要检查 D01、D04 和后续 D12/D18/D28：简短说明可见、示例先于作业、切换无重复说明、参考片段不误显示执行按钮、实验不覆盖答案、窄屏无横向溢出。完整原理继续留在 `long-reference`，不把所有原文重新铺回默认页面。
