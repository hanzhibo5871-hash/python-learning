# 实践优先版维护说明

## 使用变化

默认页面展示一项明确任务、至多三条短规则、代码与结果对照。原理、JavaScript 对照、完整错误解释保留为折叠参考。前置知识链接可回看；尚未系统展开但当前必需的语法，通过可运行卡片先说明最小用法。

39 张知识卡补充逻辑运算、异常、函数外壳、容器形状、回调、字节、装饰器和资源管理等衔接。124 道补全练习有独立编辑器；它们不是124个新的必修章节，也不宣称做完等于掌握。每题只挖一个会影响运行结果的空，再由原主作业要求独立实现。

结果表显示实际调用所得值，而非把“True”伪装成函数输出。stdout 与 stderr 分开；预期异常可以通过。旧式结构校验仍显示其真实检查项，不伪造逐输入运行结果。D24 保留真实项目端到端测试。

## 这次对齐的关键契约

D02/D03 不要求学员先发明函数外壳；平台提供的部分明确标出。D04 首次面积任务只收非负数字，D06 再回访异常。D04 默认参数不再夹带未知可变容器要求；格式化输出说明与验证统一。

D08 JSON、D09 argparse、D10 配置增加行为用例；D12 请求/响应/POST/timeout 对齐注入参数和返回结构。D13 路由统一 /tasks，异步生命周期后置为 D17 后选修。D14 明确对象 ValidationError 与 HTTP 422 的区别，移除未定义 RealRepo；D15 提供真实测试夹具，不要求学员猜测文件和 patch 路径。D17 使用 run_with_timeout 并检查取消。

D18 数据契约先通过，再增加 endpoints，输入/输出嵌套结构一致。D19 get_db_path 和入口命名公开。D21 CRUD 不提前要求首页，静态入口不提前要求 D23 HTML 存在。D22 不提前查验最终15个文件。D23 删除采用200 JSON，提示204时不可无条件解析，用户标题用 textContent。

## 状态与安全

保留全部任务/小节 ID；practice_first_revision 独立于原课程版本，因此不清空已有完成记录。历史通过只代表历史题目，新增题需重新练习，不自动标为完成。正式作业失败和成功都保存草稿；实验内容与答案分离，不创建学习进度、不写项目产物。

实验运行在临时目录，源码32 KiB、每路输出40 KB、5秒限制；子进程移除常见 API_KEY/TOKEN/SECRET 环境变量。它仍有本机用户的文件/网络权限，不是沙箱。不运行不可信代码，不把真实密钥填入练习。平台只代管示例范围，不执行 shell 命令或上传任意文件。

## 防止再次出现跳步

`practice_first.prerequisites` 由作者明确列出。加载器拒绝未来章节和必修依赖选修的声明；这不是自动证明所有自然语言依赖完整，内容修改仍需人工核对。

构建器保留详细参考，补全题先基于已有可运行例子生成；无效候选保留为示例、排除为题目。测试分别执行每张卡、每份参考实现、每份未修改 starter。每次更新均要运行完整 tool_tests，不能只跑新增测试。

自动测试不是完整学习者可用性研究，也不保证所有任意答案都正确评分。API/数据库逐阶段和最终项目验收继续承担业务检查。真实模型质量、企业接入和完整 Agent/FDE 能力不属于本次改版证明范围。
